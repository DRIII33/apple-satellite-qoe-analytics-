# Portfolio Project & Data Transparency Disclaimer

## Project Context
This project (**OrbitPulse: Apple Satellite Connectivity Telemetry Engine**) was developed independently by **Daniel Rodriguez III** as a professional portfolio demonstration of data analytics, SQL data modeling, statistical hypothesis testing, and machine learning capabilities.

---

## Data Generation Statement
* **Synthetic Origin:** All telemetry data contained within `raw_satellite_telemetry.csv`, `fact_satellite_qoe.csv`, and `agg_daily_qoe` is **100% synthetically generated** using Python (Pandas/NumPy).
* **No Confidential Data:** This repository does **not** contain, reference, or utilize any private, proprietary, or confidential data from Apple Inc. or any satellite service provider.
* **Realism Modeling:** System parameters, latency distribution curves, ground station naming conventions, and software release tags were synthetically modeled to reflect real-world satellite network monitoring challenges.
